### Array ###

**Array is used to store multiple values in a single variable so we can process them easily.**

**Basic Practice:-**

**Task 1: Create and Print**

👉 Create an array of 5 fruits and print all

```fruits=("apple" "banana" "mango" "orange" "grapes")```

Output:
```apple banana mango orange grapes```

**Task 2: Print Specific Elements**

👉 Print:

→ First fruit

→ Last fruit

Hint:

```
${fruits[0]}
${fruits[4]}
```

**Task 3: Find Length**

👉 Print total number of elements in array
